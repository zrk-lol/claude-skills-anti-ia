# Microcopy

Les petits textes sont ceux que les gens lisent vraiment, parce qu'ils sont en train d'agir. Une IA les remplit avec des formules vagues (« Soumettre », « Une erreur est survenue », « Merci ! »). Chaque libellé doit dire exactement ce qui va se passer ou ce qui s'est passé.

## Boutons

- Le bouton dit **l'action et son résultat** : « Envoyer ma demande », « Recevoir le devis », « Payer 49 € ».
- Jamais « Soumettre », « Valider », « Cliquez ici », « En savoir plus » seul.
- Un seul bouton principal par écran. Le secondaire est un lien ou un bouton discret.
- Garde la même formulation partout : si c'est « Demander un devis » dans le menu, ce n'est pas « Obtenir une estimation » en bas de page.

## Formulaires

- Le libellé au-dessus du champ, pas uniquement en placeholder (il disparaît quand on tape).
- Demande le minimum. Pour chaque champ, la question : « est-ce qu'on s'en sert vraiment ? »
- Indique le format attendu avant l'erreur : « Numéro à 10 chiffres », « 8 caractères minimum ».
- Marque les champs facultatifs « (facultatif) » plutôt que les obligatoires avec une étoile.

## Erreurs

Structure : **ce qui s'est passé + comment réparer**, sans blâmer la personne.

| Mauvais | Bon |
|---|---|
| Une erreur est survenue. | Le message n'est pas parti, la connexion a coupé. Réessaie dans quelques secondes. |
| E-mail invalide. | Il manque le @ dans l'adresse e-mail. |
| Champ requis. | Indique ton prénom pour qu'on sache comment t'appeler. |
| Erreur 500 | Ça ne marche pas de notre côté. On regarde. En attendant, écris-nous à [e-mail]. |

## Confirmations

Dis ce qui va se passer ensuite, avec un délai si possible :
« C'est envoyé. Je te réponds par e-mail sous 24 h (en semaine). »
plutôt que « Merci ! Votre message a bien été envoyé. »

## États vides

Un état vide est une invitation, pas un constat :
« Aucun projet pour l'instant. Crée le premier, ça prend 2 minutes. » + bouton.

## Bannière cookies

Courte, honnête, avec un refus aussi visible que l'acceptation :
« On utilise des cookies pour mesurer l'audience. Tu peux refuser, le site marchera pareil. » [Refuser] [Accepter]

## Page 404

Garde le ton de la marque, propose une sortie utile (accueil, recherche, contact). Une blague est permise si elle est propre à la marque, pas « Oups ! Cette page s'est perdue dans l'espace 🚀 ».

## Règles générales

- Tutoiement ou vouvoiement : le même que le reste du site, partout.
- Pas de points d'exclamation dans les messages d'erreur.
- Pas de « Oups ! », « Hmm… », « Pas de panique ! ».
- Les chiffres en chiffres : « 3 étapes », pas « trois étapes ».
